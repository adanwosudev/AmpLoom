# AmpLoom

AmpLoom empowers high-performance music production through real-time data processing processing capabilities, featuring an auto-scaling manager and multi-processor architecture.

With AmpLoom, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/AmpLoom.git`
2. `cd AmpLoom`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
